# Public visibility checklist

The scanner source and executable dependency closure are isolated from Stratus Shield. The repository is currently private and must not be made public until the repository owner confirms the remaining organisational release requirements.

Before changing repository visibility, confirm legal approval of the AGPL and contributor-licence model, review the generated SBOM and third-party notices, configure production code signing and provenance attestations, and perform a final release review. Private GitHub releases may be used for validation before those controls are complete.
